# Sprint 9 – Visual e pronto para o piloto

**Objetivo:** o produto fica bonito, limpo e rápido o bastante para mostrar a um corretor de verdade: referências dos melhores do mercado, uma revisão contra a "poluição" da tela, prédio 3D mais realista, painel e tour polidos, tour abrindo em menos de 3 s com folga e uma demo pronta para o portfólio.

**Não é objetivo:** funcionalidades novas grandes (vão para a Fase 2, `docs/01`); domínio próprio (entra quando o usuário tiver um domínio).

**Regra da tela limpa** (vale para toda issue de interface a partir daqui): cada tela tem **uma** ação principal visível; o resto fica em menu, gaveta ou aparece só quando for útil. Nada de botão novo fixo sem tirar ou esconder outro.
